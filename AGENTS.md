# Instructions for coding agents

- Treat responses as triage, not a veterinary diagnosis.
- Never recommend medications or dosages. Escalate high-risk symptoms and sudden deaths to a veterinarian or animal-health officer.
- Do not add identifiable farm or location data without a documented privacy need and consent model.
- Run `python -m pytest -q` from the repository root after backend changes.
- Keep credentials, private flock data, and unlicensed datasets out of Git.
